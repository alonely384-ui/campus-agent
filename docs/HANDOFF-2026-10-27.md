## 7. 已知的坑（都踩过，别再踩）

1. **代理**：环境变量 `HTTP_PROXY/HTTPS_PROXY` 指向 `127.0.0.1:65532`，梯子没开时端口是死的 → pip/httpx 报 `Cannot connect to proxy`。要么开梯子，要么先清：`$env:HTTP_PROXY=''; $env:HTTPS_PROXY=''; $env:http_proxy=''; $env:https_proxy=''`。
2. **NO_PROXY 重复键**：环境里同时有 `NO_PROXY` 和 `no_proxy` 时，PowerShell 启动子进程会报 `Item has already been added`；涉及 `Start-Process` 前先 `Remove-Item env:no_proxy,env:all_proxy -ErrorAction SilentlyContinue`。
3. **PS 5.1 读 .ps1 按 GBK**：脚本里写中文会报 `The string is missing the terminator` → 项目里的 `.ps1` 一律纯 ASCII。
4. **`... | Select-Object -First N` 会杀进程**：管道提前关闭把 python 中断（曾把建库跑到一半杀掉、chroma 变 0 块）。命令输出大就写文件再读。
5. **`python -c` 里连续 `asyncio.run`**：抛 `Event loop is closed`（httpx 关连接时），只影响临时脚本，uvicorn 单循环不受影响。
6. **`.pytest_cache` Permission denied** → 加 `-p no:cacheprovider`。
7. **chroma 体积误读**：`docs` 在写入瞬间可能显示偏小（曾误读 7309），以 `get_collection().count()` 平静时读为准。
8. **端口占用**：重启前先 `Get-NetTCPConnection -LocalPort 8000 -State Listen | Stop-Process -Id $_.OwningProcess -Force`。
