## 4. 数据结构口径（新会话最容易踩的地方）

### `structures.json` 有两处，别搞混

```
data/meta/structures.json     <- 默认写入位置（DEFAULT_STRUCTURES_FILE，git 跟踪，757 KB）
data/papers/structures.json   <- 旧位置（LEGACY_STRUCTURES_FILE，gitignore，972 KB）
```

逻辑在 `app/papers.py:352-384`：

```python
META_DIR = BASE_DIR / "data" / "meta"
DEFAULT_STRUCTURES_FILE = META_DIR / "structures.json"
LEGACY_STRUCTURES_FILE = PAPERS_DIR / "structures.json"
STRUCTURES_FILE = DEFAULT_STRUCTURES_FILE

def structures_file() -> Path:
    if STRUCTURES_FILE != DEFAULT_STRUCTURES_FILE or STRUCTURES_FILE.exists():
        return STRUCTURES_FILE
    return LEGACY_STRUCTURES_FILE if LEGACY_STRUCTURES_FILE.exists() else STRUCTURES_FILE

def save_structures(data):
    path = structures_file()
    if path == LEGACY_STRUCTURES_FILE:
        path = DEFAULT_STRUCTURES_FILE      # 永远不回写旧位置
```

**读的时候**：`data/meta/` 存在就用它，不存在才退到 `data/papers/`。
**写的时候**：就算当前读的是 legacy，也一律写到 `data/meta/`。

所以 `a84eafe` 之后 `data/papers/structures.json` 已经不再更新，两份内容会漂移。**真要改结构，改完确认落到了 `data/meta/`。**

### 页码是几基？

**`structures.json` 里的 page 是 0 基，对外接口一律 1 基。**

- `app/structure.py` 的 `_references()` 里 `page` 取 `lines[start]["page"]`，来源是 `for pno in range(1, max_pages)` → 0 基
- `app/agent.py:460`：`page = int(sec.get("page") or 0) + 1  # 结构里是 0 基`
- `app/reader.py` 的 `reader_meta()`：`"page": (int(ref_page) + 1 if ref_page is not None else _section_page_of(sections, "references"))`

**改任何跟页码相关的代码，先确认自己在哪一侧。**

## 7. 已知的坑（10-27 那份仍然全有效，这里只补新的）

9. **`ruff check app tests scripts` 必须在项目目录下跑**。用 `Set-Location` 到别处再跑会报
   `E902 系统找不到指定的文件 (os error 2) --> app:1:1`，看起来像配置坏了，其实只是 cwd 不对。
   验收时先 `Set-Location $ca`，再跑。

10. **PowerShell 早退出会杀进程**。`... | Select-Object -First N` 会让 python 收 SIGPIPE，
    建库或长任务跑到一半被中断（曾把 chroma 跑到 0 块）。输出大就重定向到文件再读。

11. **`Invoke-WebRequest` / `Invoke-RestMethod` 连本地调试端口会超时**，必须用 python 加
    `ProxyHandler({})` 绕开系统代理（`HTTP_PROXY=127.0.0.1:65532` 是死的）。

12. **判断文件中是否有某段中文，一律用 python `io.open(encoding='utf-8')`**。
    `(Get-Content $f -Raw).Contains('中文')` 会假阴性，害你误判"代码没生效"。

13. **改 JS/HTML 里的多行三元表达式，删一半会整块脚本不执行**。`2ac2884` 踩过：残留的
    `? ... : ''` 变成悬空分支，浏览器报 `Uncaught SyntaxError: Unexpected token '?'`，
    HTML 照渲看着正常但按钮全失灵。定位办法：CDP `Runtime.compileScript` 逐块编译内联脚本，直接拿行列号。

14. **改了后端代码要重启 uvicorn**。当前的启动命令没带 `--reload`，改完不重启，接口还是旧的。

15. **代理对 `app/online.py` 的联网抓取是致命的**。该模块统一 `httpx.Client(trust_env=False)`
    并在客户端里清代理，所以它能跑；但你另写的临时脚本要联网，得自己清 `HTTP_PROXY/HTTPS_PROXY`。
