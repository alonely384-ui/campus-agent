## 技术栈与关键数字

- 后端：Python 3.12 + FastAPI + uvicorn；前端：单文件 `web/index.html`（无框架）
- 检索：Chroma（稠密 384 维 ONNX MiniLM + 哈希兜底）+ 自建 BM25 + RRF 融合 + ms-marco-MiniLM 重排
- 语料：40 篇论文、32182 块（300 字/块、10% 重叠）、入库 25995 条
- 性能：单次检索中位 338ms（含重排）；首问冷启动约 2s（加载模型）
- 质量：**77 个自动化测试全绿**；38 题评测 top1 30/38、top3 35/38
- 不用 LangChain：链路手写，每一步可解释、可单测（答辩时能指出是哪一步出的问题）
